## 🚀 Sobre o projeto

Este repositório reúne meus estudos e práticas de **HTML5**, com o objetivo de desenvolver uma base sólida em desenvolvimento web e aplicar os conhecimentos adquiridos durante minha jornada na programação.

O projeto faz parte do meu processo de aprendizado, no qual busco compreender como as páginas web são estruturadas, explorar os recursos do HTML e evoluir gradualmente para o desenvolvimento de aplicações mais completas, entender também algumas reações da linguagem JS e entender mais sobre o posicionamento no CSS.

## 🎯 Objetivos de aprendizagem

- 📄 Compreender a estrutura de um documento HTML.
- 🏗️ Aprender a utilizar elementos e tags HTML.
- 🔗 Trabalhar com links, imagens e outros recursos de páginas web.
- 🧱 Organizar conteúdos utilizando elementos semânticos.
- 💻 Praticar a criação de páginas web.
- 📈 Construir uma base para avançar nos estudos de CSS e JavaScript.

## ▶️ Como executar

Como os arquivos HTML podem ser abertos diretamente em um navegador, não é necessário instalar dependências para visualizar páginas HTML simples.

1. Clone o repositório:

   ```bash
   git clone https://github.com/eryckferreira/project-um-discover.git
   ```

2. Acesse a pasta de estudos:

   ```bash
   cd project-um-discover/estudohtml
   ```

3. Abra o arquivo `.html` desejado no navegador ou utilize o Visual Studio Code com a extensão Live Server.
